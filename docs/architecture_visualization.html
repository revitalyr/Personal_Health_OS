🔐 Authentication

JWT tokens with refresh and revocation

Mechanisms:

  • • JWT Access Tokens (24h)
  • • Refresh Tokens (7d)
  • • Multi-factor Authentication
  • • OAuth2 / OpenID Connect

🛡️ Authorization

Role-based access control to data

Roles:

  • • Patient - access to own data
  • • Doctor - access to patients
  • • Admin - full management
  • • Scope-based access

🔒 Encryption

Data protection at all levels

Levels:

  • • TDE for PostgreSQL
  • • TLS 1.3 for traffic
  • • AES-256 for files
  • • Masking in logs
